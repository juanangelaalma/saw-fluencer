PERHITUNGAN SAW

Tahap perhitungan terbuka untuk audit.

01Matriks Keputusan

Data mentah dikonversi ke skala Likert 1–5 berdasarkan sub kriteria aktif.

X = [xij], i=influencer, j=kriteria
02Matriks Normalisasi

Benefit memakai xij / max(xj). Cost memakai min(xj) / xij.

rij = xij / max xij atau min xij / xij
03Nilai Akhir Vi

Setiap nilai normalisasi dikalikan bobot, lalu dijumlahkan untuk ranking.

Vi = Σ(wj × rij)
